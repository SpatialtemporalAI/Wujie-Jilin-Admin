# 任务管理 · 任务列表「复制」按钮 + 任务名唯一性校验

**日期**: 2026-08-03
**提出者**: 用户

## 需求概述

1. 任务列表（`任务列表` Tab）每行操作列新增「复制」按钮：点击后打开与「新增任务」相同的弹窗，把当前任务的所有业务信息（类型、地图、点位、机器人、播报、定时配置）回填进去，**排除 id / 创建时间 / 执行时间等由后端自动生成的字段**；保存后即新增一条全新任务，其余逻辑不变。
2. 复制时**任务名默认清空**，强制用户输入新名称（不复用源任务原名）。
3. 新增/编辑/复制任务时，**任务名不允许重复**（去首尾空格后比较）。

## 关键决策

- **后端零改动（指复制链路）**：复制 = 用源任务数据走现有 `POST /task/manage/add`（`fetchCreateTask`）。`id/created_at/updated_at/enabled/status/last_run_at` 等全部由后端模型层默认值自动生成；点位 `points` 提交时本就不带 `id/task_id`，自动建新点位。
- **复制时任务名默认清空**：`task-operate-drawer.vue` 的 `handleInitModel` 中 `model.value.name = operateType==='copy' ? '' : cloned.name`；弹窗打开时 `restoreValidation()` 清除校验，保存时 `validate()` 触发"请输入任务名称"。
- **任务名唯一性在后端 service 层权威校验**（参考 MerchantService/RoleService 模式）：
  - `TaskService.create`：`task_in.name.strip()` 后 `select(Task.id).where(name==stripped, deleted_at.is_(None))`，命中抛 `ConflictError(msg="任务名称已存在")`；用 `stripped_name` 落库。
  - `TaskService.update`：`update_data["name"].strip()`，与 `task_obj.name` 不同时查重并 `Task.id != task_id` 排除自身；命中抛 `ConflictError`；`update_data["name"]=stripped` 保证存干净值。
  - 全局软删除 hook（`setup_database.setup_soft_delete_plug`）本会自动过滤 `deleted_at`，这里仍显式加作双重保险，与文件内其它查询风格一致。
  - `except (NotFoundError, ConflictError)` 一起回滚抛出。
- **前端零额外改动承接唯一性**：后端 `ConflictError` → HTTP 409 + body `{code:409,msg:"任务名称已存在"}`；请求层 `onError`（`service/request/index.ts`）从 `error.response.data.msg` 读消息，经 `showErrorMsg` → `window.$message.error(msg)` 自动 toast；`handleSubmit` 见 `error` 不关弹窗、不弹成功，用户改名重试。
- **权限复用 `task:add`**（复制本质是新增），不新增后端权限种子/菜单种子。
- **不污染全局类型**：未给通用 `NaiveUI.TableOperateType` 加 `'copy'`（否则迫使 ~10 个无关 drawer 的 `Record<TableOperateType,string>` 标题映射补 `copy` 键）。改为把通用 hook `useTableOperate` 泛型化（`ExtraOperate extends string = never`），task 模块以 `useTableOperate<Api.Task.Task,'copy'>` 启用局部 `'copy'`，并在列表页本地实现 `handleCopy`。
- **复用提交逻辑**：弹窗 `handleSubmit` 本就是 `isEdit ? fetchUpdateTask : fetchCreateTask`，`isEdit = operateType==='edit'`；copy 走非 edit 的 operateType，提交自动命中新增接口，成功提示走 `addSuccess`。

## 实现范围

前端：
- `frontend/src/typings/naive-ui.d.ts`：**未改动**（保持 `TableOperateType='add'|'edit'`）。
- `frontend/src/hooks/common/table.ts`：`useTableOperate<TableData, ExtraOperate extends string = never>` 泛型化，`operateType` 类型扩为 `NaiveUI.TableOperateType | ExtraOperate`；不新增 handleCopy。
- `frontend/src/views/task/modules/task-list-tab.vue`：解构 `openDrawer` + 泛型调用；本地 `handleCopy(id)`；操作列「编辑」后加「复制」按钮（`task:add`）；操作列宽 320→380、`scroll-x` 1300→1360。
- `frontend/src/views/task/modules/task-operate-drawer.vue`：`Props.operateType` 接受 `'copy'`；标题 `copy→'复制任务'`；`handleInitModel` 回填条件覆盖 `copy` 且 **copy 时 name 清空**；`isEdit`/`handleSubmit` 不动。

后端：
- `backend/modules/task/services/task_service.py`：导入 `ConflictError`；`create`/`update` 加 name strip + 唯一性查重（update 排除自身）+ `ConflictError`；except 补 `ConflictError`。
