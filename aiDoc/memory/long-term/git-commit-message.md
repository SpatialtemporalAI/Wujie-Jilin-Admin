# Git 提交信息必须覆盖本次全部改动

## 规则

- 提交前必须逐文件查看 `git diff`（含工作区中用户手动修改的文件），把本次提交涉及的**所有**改动都写进 commit message，不能只写 AI 自己改的部分。
- 用户手动改的文案、交互、样式、格式调整，也要在 message 中单独列一条，写清「改了什么」。
- 一个提交里包含多个主题时，用正文分组列举，每组对应实际文件/行为变化。

## 适用场景

- 任何 `git add` + `git commit` 操作，尤其是用户说「和我刚刚的修改内容一起提交/推送」时。

## 来源

- 2026-11-03 用户反馈：提交 `084e141` 的 message 只描述了 AI 自己的改动（套数上限、轮询间隔），遗漏了用户刚改的「删除套间间隔说明文字」「提示语精简」「模板格式调整」等内容。
