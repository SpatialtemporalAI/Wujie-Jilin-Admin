# 机器人 WiFi 配网操作指南

> 适用场景：吉大二院人形具身智能机器人初次联网或更换网络
> 版本：V1.0 | 日期：2026-06-12

***

## 方案总览

| 方案                      | 适用场景            | 所需工具    | 操作耗时   |
| ----------------------- | --------------- | ------- | ------ |
| **A. 有线命令配网**           | 首次部署、现场无手机、批量配置 | 网线 + 电脑 | \~3 分钟 |
| **B. AP 热点配网(宇树硬件不支持)** | 无网线、运维人员用手机操作   | 手机      | \~5 分钟 |

***

## 方案 A：有线命令配网

### 前置条件

- 一根网线
- 一台电脑（Windows/Mac/Linux）
- 知道目标 WiFi 的 SSID（wifi名称） 和密码

### 操作步骤

#### 1. 配置电脑的以太网

> 目的：通过网线连接时，电脑的ip和机器人的ip在同一网段。

配置步骤：控制面板——网络和Internet——网络共享中心——更改适配器选项——双击以太网（修改对应网段ip后保存）

> 宇树机器人的默认网段为：192.168.123.x

#### 2、连接网线

将网线一端插入机器人网口，另一端连接电脑。

#### 3. 确认网络连通

电脑终端执行（以机器人默认 IP `192.168.1.100` 为例）：

```bash
ping 192.168.1.100
```

收到回复即表示连通。

> 宇树机器人默认ip：192.168.123.164
>
> 默认密码为：123

#### 3. SSH 登录机器人

```bash
ssh unitree@192.168.123.164
# 默认密码：123（首次登录后请修改）
```

#### 4. 执行配网命令

登录成功后，运行配网工具：

```bash
sudo nmcli device wifi list       #查看机器人搜索到的wifi
sudo nmcli device wifi connect “目标wifi名称” password “wifi密码”
```

1. 验证连接

```bash
# 查看连接状态
sudo nmcli connection show

# 测试外网连通
ping -c 3 8.8.8.8
```

#### 6. 断开网线

确认 WiFi 连接成功后，拔掉网线。机器人自动通过 WiFi 保持联网。

### 异常处理

| 现象            | 排查方法                                         |
| ------------- | -------------------------------------------- |
| ping 不通机器人    | 检查网线是否插紧；电脑 IP 是否与机器人同网段（如设为 192.168.1.x）    |
| SSH 连接被拒      | 确认机器人已开机且 SSH 服务已启动                          |
| WiFi 连接失败     | 检查 SSID 拼写和密码；确认 WiFi 为 2.4G 频段（部分机器人不支持 5G） |
| 连上 WiFi 但无法上网 | 检查路由器是否限制新设备接入；确认 DHCP 正常分配                  |

## 方案 B：AP 热点配网（宇树硬件不支持）

### 前置条件

- 一台手机（iOS / Android）或一台手机
- 知道目标 WiFi 的 SSID 和密码

### 原理

机器人开启自身 WiFi 热点（AP 模式），手机连接后通过浏览器访问机器人内置的配网页面，填写目标 WiFi 信息，机器人接收后切换为 STA 模式连接目标网络。

### 操作步骤

#### 1. 启动机器人（默认会启动配网模式）

> 热点 SSID 命名规则：`Robot_XXXX`（XXXX 为序列号后四位），无密码。

#### 2. 手机连接机器人热点

1. 打开手机 WiFi 设置。
2. 找到以 `Robot_` 开头的热点名称（核对序列号后四位确保是目标机器人）。
3. 点击连接。

> ⚠️ 连接后手机会暂时断开正常网络，这是正常现象。

#### 3. 打开配网页面

手机浏览器访问：

```
http://192.168.4.1（示例）
```

页面自动加载配网界面。

#### 4. 填写 WiFi 信息

1. 页面自动扫描并显示当前可用的 WiFi 列表。
2. 选择目标 WiFi（或手动输入 SSID）。
3. 输入 WiFi 密码。
4. 点击「开始配网」。

#### 5. 等待配网完成

1. 页面显示「正在配网...」。
2. 机器人接收配置后关闭热点、切换到 STA 模式连接目标 WiFi。
3. 手机自动断开机器人热点。
4. 页面跳转显示「配网成功」，机器人语音提示「网络连接成功」。

> 整个过程约 30 秒。若页面未自动跳转，检查手机是否已重新连接到正常 WiFi。

### 安全说明

| 安全机制  | 说明                      |
| ----- | ----------------------- |
| 热点时效  | 开启后 **10 分钟**内未被连接则自动关闭 |
| 连接数限制 | 最多同时允许 **1 台设备**连接      |
| 传输加密  | WiFi 密码采用 AES-128 加密传输  |
| 配网锁定  | 连续 5 次密码验证失败锁定 5 分钟     |

### 异常处理

| 现象              | 排查方法                                       |
| --------------- | ------------------------------------------ |
| 找不到 Robot\_ 热点  | 确认已长按配网按键 3 秒且指示灯蓝色闪烁；靠近机器人重试              |
| 连不上热点           | 确认手机未同时连接其他 WiFi；关闭手机 VPN；重启机器人配网模式        |
| 192.168.4.1 打不开 | 确认手机已连接 Robot\_ 热点；尝试关闭移动数据后重新访问           |
| 配网页面显示失败        | 检查 WiFi 密码是否正确；确认目标 WiFi 为 2.4G 频段；靠近路由器重试 |
| 配网后机器人不在线       | 等待 30 秒；检查路由器 DHCP 是否正常分配 IP；重启机器人         |

***

## 配网后验证

无论使用哪种方案，配网完成后按以下步骤验证：

1. 观察机器人指示灯变为**绿色常亮**（表示网络已连接）。
2. 在管理平台「机器人列表」页确认状态变为**在线**。
3. 在「运行监控」页确认能接收机器人上报的实时数据。

***

## 方案选择建议

| 场景              | 推荐方案  | 原因            |
| --------------- | ----- | ------------- |
| 首次批量部署          | A（有线） | 可脚本化批量执行，效率高  |
| 单台现场调试          | B（AP） | 无需额外设备，手机即可操作 |
| 更换 WiFi 网络      | B（AP） | 操作简单，3 分钟完成   |
| 机器人无法开机进入 AP 模式 | A（有线） | 通过网线直接操作      |
