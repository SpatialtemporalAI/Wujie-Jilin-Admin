# 机器人管理系统用户手册 

## 一、平台概述

### 1\.1 平台定位

本平台是部署在医院内网环境下的 **B/S 架构** 后台管理平台，旨在为您提供对多台人形具身智能机器人的集中控制与状态监控。核心功能涵盖：

- **机器人管理** ：展示已绑定至平台的全部机器人信息。

- **地图管理** ：场景地图的导入、编辑、切换与机器人绑定。

- **任务管理** ：任务预设、定时/即时启动、执行进度与执行历史。

- **参数配置** ：机器人唤醒词、语音合成、人脸识别、行走速度及电量阈值的个性化设置。

- **运行监控** ：机器人在线状态、运行指标（电量/信号/速度）、实时位置、视频流、与实时告警的集中查看。

- **操作日志** ：登录、操作及机器人事件的全链路追溯。

- **系统设置** ：多用户及角色的权限管理。



### 1\.2 环境与账户

### 3\.2 地图管理 （核心模块）

本模块提供从建图、编辑到场景切换的完整闭环。

#### 3\.2\.1 工作流程

1. **首次建图：** 使用手持设备对物理环境进行扫描建模。

2. **导入底图：** 在系统中导入生成的场景图片（PNG格式）。

3. **地图编辑：** 在底图上标记业务元素（点位、障碍物等）。

4. **保存地图：** 将当前编辑保存为一个独立的「场景地图」。

5. **切换与使用：** 为机器人切换不同场景地图，并基于此下发任务。

> **重要提示：**
> 
> - **新增院区区域必须重新现场扫图。**
> 
> - **切换地图前，请务必保存当前编辑内容，否则更改将丢失。**
> 
> 

#### 3\.2\.2 编辑画布交互

- **缩放：** 使用鼠标滚轮、点击 `+`/`-` 按钮或拖动滑块进行画布缩放。

- **坐标：** 底部状态栏实时显示鼠标在画布上的X/Y坐标，并支持40像素网格吸附。

#### 3\.2\.3 地图元素添加指南

您可以在画布上右键呼出菜单，添加以下元素：

| 元素类型 | 操作方式 | 交互与效果 |
|---------|---------|-----------|
| 点位 | 右键 →「添加点位」 | 1. 移动：单击并拖动。<br/>2. 重命名：双击后修改。<br/>3. 设置类型：单击后选择"返回点"或"接待点"。<br/>4. 删除：右键删除或按Del键。 |
| 障碍物 | 右键 →「新增障碍物」 | 机器人将识别并自主绕行。支持拖拽移位和双击重命名。 |
| 禁行区域/虚拟墙 | 右键 →「禁行区域/虚拟墙」 | 机器人会主动绕开该灰色阴影区域，禁止驶入。 |
| 电子围栏 | 右键 →「电子围栏」 | 进入拖拽绘制模式，框选矩形区域。机器人将无法穿越红色虚线框边界。 |

> **删除关联规则：**
>
> - **删除点位：若该点位已关联任务，任务中的该点位将被自动解除。若任务仅关联此点位，则任务本身将被删除。**
>
> - **删除地图：绑定该地图的所有任务将被一并删除。**
>
>

- **点位列表页签：** 以列表形式展示当前地图下所有点位的名称、类型与坐标，并支持逐项删除。

### 3\.3 任务管理

对任务进行创建、调度、执行与归档的全生命周期管理。

#### 3\.3\.1 核心规则

1. 任务来源： **平台预设任务** 或 **机器人语音交互产生的即时任务** 。

2. 执行互斥：同一时段只能执行一个任务。新任务将进入排队队列。

3. 跨场景失效：任务绑定场景A，若机器人被切换至场景B，则该定时任务将自动失效，不会被执行。

4. 机器人状态：机器人离线时无法启动任何任务。

#### 3\.3\.2 新建任务步骤

1. 点击「创建任务」按钮。

2. 填写基础信息：任务名称、任务类型（**播报/巡逻**）。

3. 绑定资源：选择任务所属的场景地图和目标机器人。

4. 配置任务内容：

    - **播报任务：** 填写播报文本。

    - **巡逻任务：** 选择点位，并为每个点位配置抵达后播报的语音文本及机器人动作（如"握手"、"鼓掌"等）。

5. 设置定时规则（可选）：勾选「启用定时任务」并设定日期、时间和重复周期。

6. 点击 **「保存」** ，任务将出现在任务列表中。

![未命名\.png](图片和附件/image%2010.png)

#### 3\.3\.3 任务列表

- 状态控制：可启用/禁用任务。

    - **启用时：** 任务将根据定时设置自动进入执行队列；点击「立即启动」可手动触发。（机器人不在线时，开启任务无效。）

    - **禁用时：** 任务不会自动执行，也无法手动启动。

- **编辑/删除：** 可修改任务配置或删除任务。

![未命名\.png](图片和附件/image%2015.png)

#### 3\.3\.4 执行列表

- 展示当前正在执行、等待执行或已暂停的任务。

- **控制：** 对执行中的任务进行暂停/继续（保留进度）或停止（任务取消，移至历史记录）。

### 3\.4 参数配置

本模块允许您为每台机器人（G1\-001/002/003）独立保存配置。

| 配置项 | 操作说明 |
|-------|---------|
| 唤醒词 | 1. 输入4-6个中文字符作为唤醒词。<br/>2. 点击「测试」可试听机器人响应。<br/>3. 点击「保存」后，约需1分钟生效。<br/>4. 开启「免唤醒」开关后，机器人检测到人脸即可直接交互。 |
| 语音合成 | 调节机器人的音色（男/女）、语速（0.5x-2.0x）和音量（0%-100%），支持「测试语音」试听。 |
| 人脸识别TTS | 上传人员照片并配置识别成功后的播报内容。保存后，机器人识别到该名人员后播报该指定内容。 |
| 行走速度 | 为机器人选择速度等级：低速（≤0.5m/s）、慢速（≤0.25m/s）。 |
| 电量报警 | 设置电量阈值（5%-50%）。当电量低于阈值时，系统将告警、暂停任务，并触发机器人语音提示充电。 |

## 四、运维与机器人操作

### 4\.1 机器人遥操作步骤

![image\.png](图片和附件/image.png)

请严格按照以下顺序操作机器人：

1. **开机**

    - 吊起机器人，使其处于悬挂状态。

    - **短按再长按** 遥控器电源键开机。

    - **短按再长按** 电池电源键开机。

2. **站立**

    - 调整机器人，使双脚平稳接触地面。

    - 按 **`L2 + B`** 进入阻尼状态。

    - 按 **`L2 + ↑`** 进入预备模式。

3. **进入常规运控模式**

    - 按 **`R1 + X`** ，进入常规运控模式。

    - 解开机器人两边的锁扣，使其自行站立稳定。

    - 此时，**您可以通过Web系统或语音向机器人下发任务。**

4. **关机**

    - 再次吊起机器人，使其处于悬挂状态。

    - 按 **`L2 + B`** 进入阻尼模式。

    - **短按再长按** 遥控器电源键关机。

    - **短按再长按** 电池电源键关机。
