# 语音背包wifi配网操作指南

> 适用场景：吉大二院机器人用背包网络联机以及更改网络

### 方案总览

| 方案               | 所需工具                | 操作耗时 |
| ------------------ | ----------------------- | -------- |
| A.电脑连接（推荐） | 双头USB，投屏软件，电脑 | ~2分钟   |
| B.显示器连接       | hdmi线，鼠标，显示屏    | ~2分钟   |

#### 方案A：电脑连接

##### 前置条件：

- ​       双头USB数据线
- ​       投屏软件
- ​       电脑

##### 操作步骤：

1、将背包和电脑通过双头USB线连接，背包一侧插在OTP口

2、双击启动投屏软件

3、在主界面摁住鼠标上划，可以打开应用菜单，选择设置——wifi进行连接——连接完成后可点击wifi查看IP地址

#### 方案B：显示屏连接

##### 前置条件：

- ​       hdmi线
- ​       显示屏
- ​       鼠标

##### 操作步骤：

1、将背包与显示屏通过hdmi线连接，并将鼠标插到背包上

2、在主界面摁住鼠标上划，可以打开应用菜单，选择设置——wifi进行连接——连接完成后可点击wifi查看IP地址
