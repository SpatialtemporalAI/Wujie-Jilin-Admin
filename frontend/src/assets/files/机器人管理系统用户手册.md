__机器人管理系统用户手册 __

<a id="heading_0"></a>__一、平台概述__

<a id="heading_1"></a>__1\.1 平台定位__

本平台是部署在医院内网环境下的 __B/S 架构__ 后台管理平台，旨在为您提供对多台人形具身智能机器人的集中控制与状态监控。核心功能涵盖：

- __机器人管理__ ：展示已绑定至平台的全部机器人信息。
- __地图管理__ ：场景地图的导入、编辑、切换与机器人绑定。
- __任务管理__ ：任务预设、定时/即时启动、执行进度与执行历史。
- __参数配置__ ：机器人唤醒词、语音合成、人脸识别、行走速度及电量阈值的个性化设置。
- __运行监控__ ：机器人在线状态、运行指标（电量/信号/速度）、实时位置、视频流、与实时告警的集中查看。
- __操作日志__ ：登录、操作及机器人事件的全链路追溯。
- __系统设置__ ：多用户及角色的权限管理。

<a id="heading_2"></a>__1\.2 环境与账户__

- __浏览器__：推荐 Chrome、Edge 最新版（最低版本 80 及以上），不支持 IE、老旧浏览器。
- __管理员账号__：lvya/lvya123456，首次登录需在「系统设置 \- 用户管理」修改初始密码。

<a id="heading_7"></a>__三、功能详解__

<a id="heading_8"></a>__3\.1 机器人管理__

- 功能：以列表形式只读展示当前已绑定至平台的全部机器人信息。
- 操作：点击「刷新」按钮可手动更新机器人的在线状态。

![](manual-images/image-3.png)

<a id="heading_9"></a>__3\.2 地图管理 （核心模块）__

本模块提供从建图、编辑到场景切换的完整闭环。

<a id="heading_10"></a>__3\.2\.1 工作流程__

1. 首次建图：使用手持设备对物理环境进行扫描建模。
2. 导入底图：在系统中导入生成的场景图片（PNG格式）。
3. 地图编辑：在底图上标记业务元素（点位、障碍物等）。
4. 保存地图：将当前编辑保存为一个独立的「场景地图」。
5. 切换与使用：为机器人切换不同场景地图，并基于此下发任务。

重要提示：

- 新增院区区域必须重新现场扫图。
- 切换地图前，请务必保存当前编辑内容，否则更改将丢失。

<a id="heading_11"></a>__3\.2\.2 编辑画布交互__

- 缩放：使用鼠标滚轮、点击\+/\-按钮或拖动滑块进行画布缩放。
- 坐标：底部状态栏实时显示鼠标在画布上的X/Y坐标，并支持40像素网格吸附。

<a id="heading_12"></a>__3\.2\.3 地图元素添加指南__

您可以在画布上右键呼出菜单，添加以下元素：

| 元素类型 | 操作方式 | 交互与效果 |
| :-- | :-- | :-- |
| 点位 | 右键 →「添加点位」 | 1. 移动：单击并拖动。<br>2. 重命名：双击后修改。<br>3. 设置类型：单击后选择“返回点 / 接待点 / 普通点”。<br>4. 删除：右键删除或按 Del 键。 |
| 障碍物 | 右键 →「新增障碍物」 | 机器人将识别并自主绕行。支持拖拽调整大小与位置，用于标注柱体、桌椅、设备等实体障碍。 |
| 禁行区域 / 虚拟墙 | 右键 →「禁行区域 / 虚拟墙」 | 机器人会主动绕开该灰色阴影区域，常用于标注楼梯、坡道、玻璃门等不可通行或危险区域。 |
| 电子围栏 | 右键 →「电子围栏」 | 进入拖拽绘制模式，框选矩形区域后自动生成电子围栏，机器人到达边界会触发安全停止或绕行策略。 |

删除关联规则：

- 删除点位：若该点位已关联任务，任务中的该点位将被自动解除。若任务仅关联此点位，则任务本身将被删除。
- 删除地图：绑定该地图的所有任务将被一并删除。

<a id="heading_15"></a>__3\.3 任务管理__

对任务进行创建、调度、执行与归档的全生命周期管理。

<a id="heading_16"></a>__3\.3\.1 核心规则__

1. 任务来源：__平台预设任务__ 或 __机器人语音交互产生的即时任务__。
2. 执行互斥：同一时段只能执行一个任务。新任务将进入排队队列。
3. 跨场景失效：任务绑定场景A，若机器人被切换至场景B，则该定时任务将自动失效，不会被执行。
4. 机器人状态：机器人离线时无法启动任何任务。

<a id="heading_17"></a>__3\.3\.2 新建任务步骤__

1. 点击「创建任务」按钮。
2. 填写基础信息：任务名称、任务类型（__播报/巡逻__）。
3. 绑定资源：选择任务所属的场景地图和目标机器人。
4. 配置任务内容：

- 播报任务：填写播报文本。
- 巡逻任务：选择点位，并为每个点位配置抵达后播报的语音文本及机器人动作（如“握手”、“鼓掌”等）。

1. 设置定时规则（可选）：勾选「启用定时任务」并设定日期、时间和重复周期。
2. 点击「保存」，任务将出现在任务列表中。

![](manual-images/image-10.png)

<a id="heading_18"></a>__3\.3\.3 任务列表__

- 状态控制：可启用/禁用任务。
- 启用时：任务将根据定时设置自动进入执行队列；点击「立即启动」可手动触发。（机器人不在线时，开启任务无效。）
- 禁用时：任务不会自动执行，也无法手动启动。
- 编辑/删除：可修改任务配置或删除任务。

![](manual-images/image-11.png)

<a id="heading_19"></a>__3\.3\.4 执行列表__

- 控制：对执行中的任务进行暂停/继续（保留进度）或停止（任务取消，移至历史记录）。

![](manual-images/image-12.png)

- 点击「查看详情」可查阅任务执行的完整轨迹、停留时长及最终结果。

<a id="heading_22"></a>__3\.5 运行监控__

集中查看机器人的实时状态。

- 切换机器人：通过顶部下拉菜单选择要查看的机器人。

- 视频监控：实时播放机器人前置摄像头画面，支持全屏查看。
- 实时告警：按严重程度（严重故障/告警提示/正常恢复）分类展示，帮助您快速定位问题。

<a id="heading_23"></a>__3\.6 日志管理__

提供全平台事件审计能力，分为三个页签：

- 登录日志：记录所有用户的登录历史，可按时间、用户名、IP及状态筛选。
- 操作日志：记录用户在平台上的关键操作，支持查看操作前后的数据快照。
- 机器人事件日志：记录机器人端的故障与告警事件。
- 筛选：支持按机器人、事件状态及时间范围组合筛选。
- 操作：支持单行删除、批量删除、清理日志及导出功能。
- 列设置：您可自定义表格中显示/隐藏的字段。

<a id="heading_25"></a>__四、运维与机器人操作__

<a id="heading_26"></a>__4\.1 机器人遥操作步骤__

![](manual-images/image-27.png)

请严格按照以下顺序操作机器人：

1. 开机

- 吊起机器人，使其处于悬挂状态。
- 短按再长按遥控器电源键开机。
- 短按再长按电池电源键开机。

1. 站立

- 调整机器人，使双脚平稳接触地面。
- 按 L2 \+ B 进入阻尼状态。
- 按 L2 \+ ↑ 进入预备模式。

1. 进入常规运控模式

- 按 R1 \+ X，进入常规运控模式。
- 解开机器人两边的锁扣，使其自行站立稳定。
- 此时，__您可以通过Web系统或语音向机器人下发任务。__

1. 关机

- 再次吊起机器人，使其处于悬挂状态。
- 按 L2 \+ B 进入阻尼模式。
- 短按再长按遥控器电源键关机。
- 短按再长按电池电源键关机。
