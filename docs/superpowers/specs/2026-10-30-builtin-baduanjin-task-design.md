# 内置八段锦任务设计

## 目标

将现有“八段锦1111”表演任务迁移为固定 `id=1`、名称“八段锦”的内置任务。内置任务只允许查询列表和详情，所有执行与写操作均禁止；迁移同时作为新环境的种子数据来源。

## 数据模型与迁移

- `task` 新增 `is_builtin: Boolean NOT NULL DEFAULT false`，ORM、响应 Schema 和前端 `Api.Task.Task` 同步增加该字段。
- 新增 `0020_seed_builtin_baduanjin_task.py`，`down_revision="0019"`。
- 当前源任务 ID 为 `3729332729099264`，包含三套八段锦动作、一个机器人关联和 38 条已结束执行记录，没有进行中的执行记录。
- 迁移采用“复制主记录 → 转移关联 → 删除旧主记录”：
  1. 将源任务复制为 `id=1`、名称“八段锦”、`is_builtin=true`，保留原业务字段和时间字段。
  2. 将 `task_robot.task_id`、`task_point.task_id`、`task_execution_record.task_id` 从旧 ID 改为 `1`。
  3. 删除旧主记录，避免修改外键约束。
- 新环境没有源任务时，插入固定 ID 的内置种子，内容为 `baduanjin_1/2/3`，分别使用 `bdj_1/2/3`，每套播放一次，前两项间隔 10 秒，最后一项间隔为 `null`。
- 如果 `id=1` 已被无关任务占用，迁移抛出错误，不覆盖该数据。
- 回退时，迁移产生的数据恢复原主 ID、原名称和关联；纯种子数据删除，最后移除 `is_builtin` 字段。

## 后端只读约束

- 在任务服务中提供统一内置任务校验，冲突时返回“内置任务仅支持查看”。
- 更新、删除、启用/禁用在读取任务后立即校验。
- 启动、暂停整个任务、暂停/恢复/停止单条执行记录均校验来源任务；管理接口与开放 API 复用服务层约束。
- 列表、任务详情、执行记录列表和执行详情保持可查询。
- 任务列表查询按 `is_builtin DESC, id DESC` 排序，使内置任务在所有分页和筛选结果中排最前，普通任务仍按 ID 倒序。
- 复制属于新增任务，前端隐藏内置任务的复制入口；普通新增仍沿用现有“八段锦”保留名称校验。

## 前端展示

- 任务列表名称列使用自定义渲染，在名称旁显示小型“内置”标签，不增加独立列。
- `is_builtin=true` 的行隐藏启动、暂停、编辑、复制、启用/禁用和删除按钮，操作列显示 `-`。
- 其他任务的操作、权限和展示保持不变。

## 验证

- 后端语法检查及内置任务服务约束检查。
- 在事务中验证迁移和回退逻辑，确认 ID、名称、内置标识、机器人关联、执行记录数量及种子内容，随后回滚测试事务。
- 前端 TypeScript 类型检查、相关文件 ESLint 和生产构建。
- 核对普通任务行为不受影响，内置任务仍可从列表及执行详情查询。
- 验证不同分页和筛选条件下内置任务均排在普通任务之前，普通任务相对顺序不变。
